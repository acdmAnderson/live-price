# live-price

`live-price` é um laboratório local de engenharia para construir uma plataforma fictícia de inteligência de preços em tempo real.

O projeto recebe preços sintéticos e imperfeitos, usa IA para normalizá-los e investigá-los, mede sua confiabilidade com sinais da comunidade e disponibiliza dados de acordo com o nível de evidência disponível.

Não é um produto que será lançado. É uma jornada prática para aprofundar IA aplicada, sistemas distribuídos, Kubernetes, dados, observabilidade e decisões de arquitetura no contexto de um Forward Deployed Engineer.

O plano de aprendizagem está em [docs/plan/learning-roadmap.md](docs/plan/learning-roadmap.md).
